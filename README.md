## Explainable AI for credit-card attrition

`xai_attrition/` is an end-to-end XAI framework that explains an ANN's predictions of which
cardholders will leave. See [xai_attrition/README.md](xai_attrition/README.md) and the sample
report in [outputs/report.md](outputs/report.md). To run it: `python -m xai_attrition`.
